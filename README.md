## О проекте

Адаптивный одностраничный лендинг в стиле MoGo. Проект собран на чистом HTML, CSS и JavaScript с использованием `jQuery` и `Slick Carousel`.

Live Demo: https://joehflu.github.io/MoGo-free-layout/

## Возможности

- фиксированный хедер при скролле
- плавная навигация по секциям
- мобильное меню
- аккордеон в блоке `What we do`
- слайдер отзывов
- адаптивная сетка для desktop, tablet и mobile

## Стек технологий

- HTML5
- CSS3
- JavaScript
- jQuery
- BEM
- Slick Carousel
- Font Awesome
- Google Fonts

## Структура проекта

- `index.html` - основная разметка страницы
- `assets/css/style.css` - стили и адаптив
- `assets/js/app.js` - поведение страницы
- `assets/images/` - изображения и графика

## Примечания к проекту

- Это статический фронтенд-лендинг.
- Это моя первая самостоятельно сверстанная страница.
- Структура основана на оригинальном шаблоне MoGo free PSD template by Laaqiq.
